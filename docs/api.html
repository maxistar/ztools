API

API entry page for sub-pages.

Core runtime files

  • core.js — reactive primitives: signal, computed, effect, batch, onCleanup
  • dom.js — DOM builder, props/attrs/events, Show, For
  • enhance.js — progressive enhancement and mounting helpers

Platform files

  • ssr.js — server-side rendering helpers (h, tags, renderToString, rawHtml)
  • wc.js — Web Components adapter (defineComponent)
  • css.js — optional css template helper

Entry points

  • ztools.js — default exports
  • ztools.client.js — client-oriented entry
  • ztools.ssr.js — SSR-only entry
