# ztools.js

Default package entry point.

## Import example

```js
import { signal, createTags, mount } from "@ztools.org/runtime";
```

## When to use

Use this entry for general client runtime usage when you want the default public API surface.

Re-exports:
- `./src/core.js`
- `./src/dom.js`
- `./src/enhance.js`
